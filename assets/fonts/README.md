# UI font

Roboto Condensed by the Roboto Project Authors, licensed under the SIL Open
Font License 1.1 (see OFL.txt). Source:
https://github.com/google/fonts/tree/main/ofl/robotocondensed

RobotoCondensed.ttf is the original variable font downloaded October 19, 2026.
The UI uses weight 500 at 11/14/18/24/32 logical pixels. The embedded atlas is
rasterized at twice those sizes with Pillow, preserving lowercase and printable
ASCII punctuation. Unsupported characters display a question mark.

Regenerate with `python tools/generate_font_atlas.py` from an environment with
Pillow installed. Ordinary builds need no Python, font library or external font
files. The generated atlas is compiled into the game. Distributions include
this attribution and OFL.txt under share/urban-sim/fonts.
